# Updainium Security

Updainium takes security seriously, particularly given its focus on privacy and anonymity. We welcome responsible vulnerability reports to maintain trust with our users.

## How to Report Vulnerabilities

We accept vulnerability reports responsibly. To protect your anonymity, we provide multiple channels:

To report a security issue, please [open a security advisory](https://github.com/livrasand/Updainium/security/advisories/new) on GitHub with a detailed description of the issue, the steps you took to create the issue, affected versions, and, if known, mitigations for the issue.

## What to Include in the Report
- Clear description of the vulnerability.
- Steps to reproduce it.
- Potential impact.
- Suggested mitigations (optional).

## Response Timeline
- Acknowledgment of receipt within 7 business days.
- Status updates every 7-14 days.
- Resolution of critical vulnerabilities within 30 days.

## What NOT to Report via Public Issues
- Do not create public issues for unconfirmed vulnerabilities.
- Avoid discussing exploit details in public.
- Do not use issues for general security inquiries.

## Policies
- No legal action will be taken against good-faith reports.
- Anonymous reports may receive credit if requested (optional).
- We adhere to standards such as [Responsible Disclosure](https://en.wikipedia.org/wiki/Responsible_disclosure).

If you have questions, contact us anonymously.

## Preferred Languages

We prefer all communications to be in Spanish.

## Gist Privacy

GitHub Gists used for backups are **public by design**. Anyone with the gist URL can read the backup contents. Backup gists are not indexed by search engines but are accessible without authentication. To protect your data:

- Use long, randomly generated gist URLs (GitHub does this automatically)
- Do not share gist URLs publicly
- Treat backup gists as publicly readable; do not store highly sensitive secrets in them

If you need private backups, export your settings locally instead of using GitHub Gists.

Thank you for helping keep Updainium secure.
